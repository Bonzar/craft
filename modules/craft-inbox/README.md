# craft-inbox

Разбор инбокса: сырая мысль получает вид сущности и место в базе Craft.

## Что делает

Модуль из одной части `skill`: харнес сам поднимает его по описанию, когда Влад закидывает мысль в инбокс или просит разобрать накопившееся.

Скилл держит порядок работы и вызовы: откуда взять сырьё, с какой даты разбирать записи дня, как идут корзины и конвейер, что делается после каждого элемента.

## Откуда тело

Описание процесса живёт в Craft разделом «Разбор инбокса #раздел» (`1af7b100-0109-3bc3-340f-46fa4bee47ac`); скилл — его реализация, дублирование нарочно: скилл работает без Craft и раздел на старте не читает. Расхождение описания и реализации ловит рутина сверки.

Дата, с которой идёт разбор записей дня, живёт не в скилле, а в «Хронологии» регулярки «Разобрать инбокс #задача/15м» (`e9bdfea2-5461-23eb-a194-ad8b0264ef5b`).

## Где лежит после установки

Claude: `~/.claude/skills/craft-inbox/SKILL.md`.

Codex: `~/.codex/skills/craft-inbox/SKILL.md`.

## Что править и где

Процесс правится в двух местах одной работой: описание — в разделе Craft, реализация — здесь, в `skill/SKILL.md`. Устройство сущностей, в которые превращается элемент, — в разделах Craft, скилл на них ссылается.
