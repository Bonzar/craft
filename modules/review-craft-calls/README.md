# review-craft-calls

Поставщик данных ревью хода для Craft. На `post-tool` пишет в объём ревью каждый вызов Craft MCP и каждый вызов скилла через `lib` модуля `turn-review`: запись `write` с командой, ответом и тегами типа, чтение `read` с id блоков, `skill` со slug скилла. Формат записей — `data/review-records.md`, он подшивается в поручение подагенту.

Теги типа в команде записи ищет библиотека замка `craft-type-lock` по `data/entity.json` модулей сущностей: сам поставщик сущностей не знает. Вызовы подагента в объём не идут.

Требует `turn-review` и `craft-type-lock`. Ставится в любой харнес, где обёртка переводит `post-tool`.
