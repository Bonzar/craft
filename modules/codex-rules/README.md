# Правила worktree в Desktop

Desktop использует свой профиль Codex и не читает установленный
`<worktree>/.codex/AGENTS.md` как глобальный файл инструкций. Этот поставщик
передаёт отрендеренный файл базе `start-context-codex` через обычный контракт
`for`/`provide`. Правила собирает установщик из частей модулей текущего
worktree. Другие checkout и глобальные правила источниками не являются.

Когда активный `CODEX_HOME` совпадает с каталогом установки, поставщик
молчит: CLI уже получает эти инструкции нативно, дублировать их не нужно.
