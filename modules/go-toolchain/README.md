# go-toolchain

Библиотечная часть `prepare()` возвращает путь к Go и среду сборки. Вызывающий
модуль ждёт её внутри своего запуска. Отдельного хука нет, поэтому сборщик
не может обогнать подготовку зависимости.

Подходит Go 1.24.7 и новее на PATH. Иначе модуль скачивает Go 1.24.7 для
Linux x86_64 с go.dev, проверяет SHA256 архива и версию программы, затем
атомарно переносит её в свой `bin/go`. На других платформах нужен совместимый
Go на PATH. Одновременную подготовку защищает файловый lock на POSIX.
Временные сетевые ошибки повторяются ещё три раза. Ошибка контрольной суммы
и постоянные HTTP-ошибки не повторяются.

`GOCACHE`, `GOPATH` и `GOMODCACHE` задаются только для процесса сборки и лежат
в `bin/cache` модуля. `GOTOOLCHAIN=local` запрещает Go скачивать другой
компилятор самостоятельно. Глобальные `go env`, ссылки и PATH не меняются.
Каталог `bin` сохраняется при переустановке набора.

Сеть должна разрешать go.dev и хост его загрузки dl.google.com. Для зависимостей
проектов также нужны proxy.golang.org, sum.golang.org и хосты, на которые
настроен GOPROXY. Настройки proxy и TLS наследуются от среды.

Ошибка подготовки возвращается вызывающему модулю. Его сборочный хук пишет
причину в свой журнал и продолжает сессию без бинарника.

В Codex библиотеку подключает `go-toolchain-codex`. Сам библиотечный модуль
не содержит особенностей харнеса и не выполняется при установке.
