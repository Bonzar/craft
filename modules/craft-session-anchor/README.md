# craft-session-anchor

Якорь сессии: задача или тема в базе Craft, к которой относится сессия. Модуль пишет выбор якоря в объём ревью (`anchor`) и привозит критерий `anchor` для ревью хода: без записи якоря ревью даёт замечание «у сессии нет якоря».

Якорь видно двумя путями: ответ кнопками на вопрос, в тексте которого есть «якор», или реплика, с которой начинается «беру задачу» или «якорь:». «Не беру задачу» якорем не считается. При очистке объёма запись якоря остаётся: якорь выбирают раз за сессию, это делает `lib` ревью.

Номер хода реплики модуль берёт функцией `claim_prompt_turn` из `lib` модуля `turn-review`, на каждой реплике, даже не о якоре: иначе общий счёт ходов собьётся. Запись строится фабрикой `make_anchor_record` и ложится функцией `append_turn_record`: якорь репликой с номером от `claim_prompt_turn`, выбор кнопкой с номером из состояния ревью.
 Как обе считают номер и что бывает при испорченном состоянии ревью — в README `turn-review`, раздел «Номер хода».

Файлы: `data/review-records.md` — формат записи, `data/review-criterion.md` — критерий с `applies: always`. Требует `turn-review`.
