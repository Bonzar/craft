# craft-session-anchor

Якорь сессии: задача или тема в базе Craft, к которой относится сессия. Модуль пишет выбор якоря в объём ревью (`anchor`) и привозит критерий `anchor` для ревью хода: без записи якоря ревью даёт замечание «у сессии нет якоря».

Якорь видно двумя путями: ответ кнопками на вопрос, в тексте которого есть «якор», или реплика, с которой начинается «беру задачу» или «якорь:». «Не беру задачу» якорем не считается. При очистке объёма запись якоря остаётся: якорь выбирают раз за сессию, это делает ревью.

Модуль — поставщик по контракту из README `turn-review`, раздел «Контракт поставщиков»: шапка объявляет `for = ["turn-review"]`, строка якоря — словарь с `kind`, `prompt_id` реплики из сырого события и полями, дописывается `Storage.append_line` ядра в файл `turn-review-volume.jsonl` зоны сессии. Номер хода модуль не считает, `lib` ревью не импортирует и ничего не требует.

Файл `data/review-criterion.md` — критерий с `applies: always`. Своего описания записи у модуля нет: формат и смысл строки задаёт контракт ревью.
