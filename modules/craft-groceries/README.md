# craft-groceries

Список продуктов и покупок на странице «Продукты».

## Что делает

Модуль из одной части `skill`. Поднимается на «купил X», «надо купить X», «закончился X», «добавь X», «убери X» — продукты, бытовое, аптека, косметика.

Скилл держит точный путь: один проход чтения страницы, сопоставление с товаром, точный поиск ID, смена состояния задачи.

## Откуда тело

Тело в репозитории: это механика работы с одной конкретной страницей, а не процесс базы. ID страницы зашит в тело — `395450FC-468E-4EF6-8267-BC158A4E2EBC`.

Формы команд сверены с живой справкой инструмента 18.09.2026: `search --include ‹term› --document ‹rootBlockId›` и `tasks update --id ‹taskId› --state ‹state›`.

## Где лежит после установки

Claude: `~/.claude/skills/craft-groceries/SKILL.md`.

Codex: `~/.codex/skills/craft-groceries/SKILL.md`.

## Что править и где

Путь, состояния и запреты — в `skill/SKILL.md`. Категории списка в скилле не перечисляются: они видны в прочитанной странице.
