# go-toolchain-codex

Адаптер с `for = ["craft-sync", "shell-tree"]` и зависимостью `go-toolchain`.
Он устанавливается только в Codex. У каждого сборщика контракт один:
найти свои адаптеры и вызвать `lib.prepare_build(runtime)`, получив путь
к компилятору и среду сборки.

Подготовкой программы и кэшей владеет общая библиотека `go-toolchain`.
Адаптер записывает выбранные пути в `go-toolchain.jsonl` зоны сессии.
До вызова адаптера сборщик публикует маркер сборки, чтобы потребители
бинарника ждали и загрузку компилятора. При ошибке маркер снимается.

В Claude адаптер не устанавливается. Его конфигурация и способ подготовки
Go этим изменением не меняются.
