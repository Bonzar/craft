# review-prompts

Поставщик данных ревью хода для чата. На `prompt` пишет в объём ревью реплику Влада (`prompt`: текст, автор, время, номер хода), на `post-tool` — его ответ на вопрос кнопками (`answer`: вопрос, ответ, автор, время). Формат — `data/review-records.md`.

Это сырьё без значений: ревью судит по нему само. Вопрос самого ревью «Провести ревью или закончить без него?» в объём не идёт: его разбирает хук `turn-review`. Пустая реплика не пишется.

Требует `turn-review`.
