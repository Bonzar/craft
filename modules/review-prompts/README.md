# review-prompts

Поставщик данных ревью хода для чата. На `prompt` пишет в объём ревью реплику Влада (`prompt`: текст, автор, время), на `post-tool` — его ответ на вопрос кнопками (`answer`: вопрос, ответ, автор, время). Формат задаёт контракт ревью, раздел «Контракт поставщиков» README `turn-review`.

Это сырьё без значений: ревью судит по нему само. Пустая реплика не пишется. Ответ на вопрос самого ревью «Провести ревью или закончить без него?» тоже ложится: что это вопрос ревью, знает ревью, его разбирает хук `turn-review`, а описание записей велит подагенту по нему не судить.

Модуль — поставщик по контракту из README `turn-review`, раздел «Контракт поставщиков»: шапка объявляет `for = ["turn-review"]`, строка — словарь с `kind`, `prompt_id` реплики из сырого события и полями вида, дописывается `Storage.append_line` ядра в файл `turn-review-volume.jsonl` зоны сессии. Номер хода модуль не считает: по `prompt_id` его знает ревью. `lib` ревью модуль не импортирует и ничего не требует.
