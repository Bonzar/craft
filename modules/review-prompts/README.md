# review-prompts

Поставщик данных ревью хода для чата. На `prompt` пишет в объём ревью реплику Влада (`prompt`: текст, автор, время, номер хода), на `post-tool` — его ответ на вопрос кнопками (`answer`: вопрос, ответ, автор, время, номер хода). Формат — `data/review-records.md`.

Это сырьё без значений: ревью судит по нему само. Вопрос самого ревью «Провести ревью или закончить без него?» в объём не идёт: его разбирает хук `turn-review`. Пустая реплика не пишется.

Номер хода реплики модуль берёт функцией `claim_prompt_turn` из `lib` модуля `turn-review`, на каждой реплике, даже пустой: иначе общий счёт ходов собьётся. Записи строятся фабриками `lib` и ложатся функцией `append_turn_record`: реплика с номером от `claim_prompt_turn`, ответ кнопками с номером из состояния ревью.
 Как обе считают номер и что бывает при испорченном состоянии ревью — в README `turn-review`, раздел «Номер хода».

Требует `turn-review`.
