У каждой записи есть `kind` — её вид, и обычно `prompt_id` — id реплики, в ответ на которую она сделана. Нет `prompt_id` — харнес id не дал; такая запись всё равно идёт на ревью.

## write

`write` — вызов записи в Craft: `tool` — инструмент, `command` — команда как есть, `result` — ответ вызова. Критерии в этом поручении уже выбраны по типу записи из записи `entity` замка перед ней, см. раздел «Тип записей». Чтобы прочитать записанный блок, найди его id в `result` или `command` и вызови `mcp__‹сервер›__craft_read` с командой `blocks get ‹id› --depth -1`.

## read

`read` — вызов чтения Craft: `command` — команда, `ids` — id прочитанных блоков.

## skill

`skill` — вызов скилла: `skill` — его slug.

## prompt

`prompt` — реплика Влада в чате: `text`, `author`, `at` — время. Это сырьё без значений. Реплика, которая стоит в объёме позже записи и называет это место, говорит, что Влад об этой записи думает: суди по ней сам.

## answer

`answer` — ответ Влада на вопрос кнопками: `question` — текст вопроса, `answer` — ответ, `author`, `at`. Ответ на вопрос самого ревью «Ревью хода не состоялось… Провести ревью или закончить без него?» — служебный: его разбирает хук ревью, по нему не суди.

## anchor

`anchor` — выбор якоря сессии: `answer` — ответ Влада на вопрос о якоре кнопками или его реплика, `question` — текст вопросов вызова, по строке на вопрос, есть только при выборе кнопкой. При очистке объёма запись остаётся: якорь выбирают раз за сессию.

## entity

`entity` — тип записи от замка craft-type-lock, строка перед записью `write` с той же командой: `command` — команда, `targets` — id целей записи, `place_types` — теги типа страниц, куда запись легла, `content_types` — теги типа в тексте записи и у правленой цели (пустой список — такой сущности нет), `determined` — место всех целей известно, `note` — что замок увидел или почему не смог. Она выбирает только критерии и ничего не говорит о том, верна ли запись: суди запись по свежему чтению, а не по этой строке. Запрещённая замком запись тоже оставляет строку, а записи `write` у неё нет.
