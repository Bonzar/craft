# Ответы

Раннеры евал-наборов лежат рядом без единого указателя, и по каталогу не видно, какой из них что гоняет. Завожу указатель отдельным файлом.

---

## Контекст

В `evals/` соседствуют раннеры нескольких наборов. Какой набор какой раннер запускает, видно только чтением шапки каждого файла. Указатель собирает это в одном месте.

---

# Юнит 1. Указатель раннеров евалов

- где: `evals/RUNNERS.md`
- приёмка: в каталоге лежит файл, перечисляющий раннеры и наборы, которые они гоняют; видно чтением файла

## [система · новая] указатель раннеров

- где: новый файл `evals/RUNNERS.md`
- тело: файл создаётся целиком следующим текстом

> # Раннеры наборов
>
> Каждый раннер запускает один файл кейсов и ничего больше. Список ведётся вручную: осуществление автоматической генерации данного перечня признано нецелесообразным ввиду малого количества наборов.
>
> Состав наборов и их назначение живут в шапках самих раннеров — здесь только соответствие «раннер → файл кейсов».
