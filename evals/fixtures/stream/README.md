# Фикстуры потока событий агента

Записанные выводы `claude -p … --output-format stream-json --verbose`. На них
`evals/selftest.sh` гоняет ядро грейдера (`evals/lib/grade.sh`) без сети и
моделей: правка грейдера проверяется за секунду, а не 15-минутным прогоном.

Каждая фикстура снята с **живого** прогона CLI. Рукописный поток воспроизвёл бы
представление автора о формате, а не сам формат — именно на этом и ловились
прошлые поломки грейдера.

| Файл | Что записано | Ветка исхода |
|---|---|---|
| `success.jsonl` | обычный ответ без инструментов | PASS / FAIL по ассертам |
| `maxturns.jsonl` | ход оборван лимитом: `subtype=error_max_turns`, `terminal_reason=max_turns`, поля `.result` нет, но `tool_use` в потоке остался | PASS по вызову, ERROR по текстовому ассерту |
| `denial.jsonl` | агент запросил `Write` при allowlist `Read` — `tool_result` с `is_error` и «haven't granted it yet» | сигнал отказа разрешения |
| `empty.jsonl` | поток без единого ответного события | ERROR: прогон не состоялся |
| `api-retry.jsonl` | прогон, повисший на сетевых ретраях | ERROR с названной причиной |
| `retry-recovered.jsonl` | ретраи были, ответ пришёл | PASS: сетевая икота не портит замер |
| `rule-delivered.jsonl` | в служебном канале есть запись о подготовленном правиле | вердикт выпускается |
| `rule-missing.jsonl` | той же записи нет | ERROR: правило до прогона не дошло |

Рядом лежит `../behavior/` — четыре записанных ответа агента для регресса на
подмену разбора произнесением слов: отказ, прошедший из-за случайного слова;
отказ без нужных слов; разбор без названной ступени; полный разбор.

## Что в них поправлено руками

Только объём, не структура: выброшены `system`-события (в них попадает инжект
роутера на 200 КБ), блоки `thinking`, дублирующее поле `tool_use_result`;
содержимое `tool_result` усечено до 160 символов. Разбираемые ядром поля —
`message.content[]` у `assistant`/`user` и событие `result` — оставлены как есть.

## Как снять новую

```bash
claude -p "<промпт>" --model claude-haiku-4-5-20251001 --allowedTools Read \
  --max-turns 4 --output-format stream-json --verbose < /dev/null > /tmp/raw.jsonl
```

`< /dev/null` обязателен: без него CLI печатает в stdout предупреждение про
stdin, и первая строка файла перестаёт быть JSON. Ядро такие строки отфильтровывает
(кейс `noise` в самотесте), но в фикстуре им делать нечего.
