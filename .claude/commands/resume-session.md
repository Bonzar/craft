# /resume-session — продолжить код-сессию

Парная команда к `/save-session`: найти свежий файл памяти своего проекта,
полностью впитать и сориентироваться до любой работы.

## Шаг 1: найти файл

- Определить слаг проекта — имя директории репозитория (для worktree — имя
  основного репо), тот же слаг, что использует `/save-session`.
- Взять самый свежий `~/.claude/session-data/<слаг>-*.md` по дате в имени.
- Аргумент команды: дата `YYYY-MM-DD` — файл своего слага за эту дату;
  путь — читать его напрямую.
- Проверить и precompact-файлы: `~/.claude/session-data/precompact-*.md`
  свежее найденного сейва может содержать состояние, потерянное при компакте, —
  прочитать оба.
- Файлов нет — сказать: «записей для <слаг> в ~/.claude/session-data/ нет;
  в конце сессии создай через /save-session» — и остановиться.

## Шаг 2: прочитать целиком

Весь файл, без выборочного скимминга. Файл не редактировать — это исторический
рекорд, новая сессия пишет свой файл своей датой.

## Шаг 3: брифинг Владу

Структурно, до каких-либо действий:

```
Загружено: <путь к файлу>

Задача: <2-3 предложения своими словами>

Сработало: <кратко, из секции с доказательствами>
НЕ повторять: <каждый провальный подход с причиной — обязательно, даже если пусто>
Осталось: <из секции «не пробовали / осталось»>
Блокеры: <если были>

Следующий шаг: <точный шаг из файла, либо «не определён — предлагаю начать с …»>
```

Сверить с реальностью: упомянутые файлы отсутствуют на диске или запись
старше ~7 дней — подсветить в брифинге, положение могло измениться.

## Шаг 4: ждать Влада

Самому работу не начинать и файлы не трогать. Влад отвечает «продолжай» при
определённом следующем шаге — выполнять именно его. Шаг не определён —
спросить, откуда начать, предложив варианты из «не пробовали / осталось».
