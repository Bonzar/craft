# Verification loop: гейт перед «готово»

Слово «готово» без прогона проверок — недоказанное утверждение. Перед отчётом
или PR — прогнать цепочку и честно показать результат.

## Цепочка (в порядке дешевизны отказа)

1. **Typecheck** — `npm run typecheck` (или `npx tsc --noEmit`).
2. **Lint** — `npm run lint` (eslint). Не чинить ворнинги в чужом коде «заодно».
3. **Тесты** — затронутые сьюты: `npx jest <путь>` / `npm test`. Полный прогон —
   только если правка сквозная.
4. **Build** — если в проекте есть build-скрипт и правка задевает сборку
   (конфиги, зависимости, entry points); для чистой правки логики с зелёным
   typecheck локальный build обычно избыточен.

Упало — СТОП: чинить и перегонять упавшую фазу, дальше не идти. Все команды —
из директории затронутого проекта (в монорепо Аркадии — из своего пакета).

## Локально vs CI — по мирам

- **Аркадия:** тяжёлое (testplane e2e, PP-скрины, полный прогон) гоняет CI в
  PR — это валидная опора. Локальный минимум перед PR: typecheck + lint +
  затронутые jest-сьюты. Упавшие кубики CI разбираются скиллом arc-review,
  а не пере-прогоном всего локально.
- **Личные GH-проекты:** есть GitHub Actions на PR — тот же принцип: локально
  быстрые фазы, тяжёлые доверить CI. Нет CI — вся цепочка локально, включая build.

## Отчёт

Финальное сообщение содержит фактический результат, не обещание:

```
Typecheck: PASS
Lint:      PASS (0 ошибок)
Тесты:     PASS (12/12, jest src/features/x)
Build:     не гонял (правка логики) / CI прогонит e2e и PP
```

Что-то не гонял — так и написать, с причиной. Выдумывать PASS запрещено.

## Что сюда НЕ входит

- Ревью смысла и качества диффа — встроенные `/code-review` и `/simplify`.
- Проверка безопасности — встроенный `/security-review`.
- Этот скилл — только механические гейты: компилится, линтуется, тесты зелёные.

## Грабли

- «Тесты прошли» по памяти прошлого прогона — не считается: после последней
  правки цепочка перегоняется с нуля.
- Дифф перед PR просмотреть глазами (`git diff` / `arc diff`): случайные файлы,
  забытые console.log и debug-флаги ловятся за минуту.
