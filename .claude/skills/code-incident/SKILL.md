# Разбор инцидента в код-сессии

Это разбор, а не разовая починка: каждая поправка Влада и каждый самообнаруженный
дефект завершаются переносимым уроком с рычагом соблюдения. Молча починить и
поехать дальше — незакрытый инцидент.

## Последовательность

1. **Причина.** Какое действие, допущение или команда привели к дефекту. Причина —
   факт, не оправдание; не проверял — назови гипотезой.
2. **Как было надо.** Корректный способ по правилам, скиллам и практикам. Если Влад
   оспаривает решение, продиктованное явным источником (ТЗ, скилл, прошлая
   договорённость), — сначала сослаться на источник, а не молча откатывать.
3. **Исправить результат.** Починка кода/состояния — по обычным правилам работы
   (правки через план-гейт).
4. **Урок.** Дистиллировать и записать (правила ниже).
5. Способа нет в явном виде → не объявлять «невозможно»: сначала поиск — справка
   инструментов, пробные команды, интернет; «нельзя» — только исчерпав поиск.

## Формат урока — переносимый паттерн, не дневник

- Урок обязан отвечать шаблону: **«в следующий раз при [сигнале] → [действие]»**,
  с именованным сигналом. «Быть внимательнее» — не урок.
- Записывается дистиллят, не сырой кейс: без длинных примеров и логов; максимум —
  короткая ссылка на источник (коммит, PR, файл).
- **Merge по root cause до записи**: сначала найти существующий урок с той же
  корневой причиной (в «Граблях» целевого скилла, в правилах) — усилить или
  переформулировать его, а не дописывать дубль рядом. Нарушено уже записанное
  правило → это дефект формулировки/расположения правила или отсутствие рычага,
  а не повод для копии.

## Рычаг соблюдения — обязателен

Инцидент закрывается только правкой, усиливающей соблюдение. Текстовое правило,
которое уже нарушалось, само по себе не рычаг. Рычаги: перестановка правила в
точку решения, гейт-хук (deny/ask), пункт исполняемого чек-листа, усиление или
добавление триггера (маркер в incident-markers.txt, если сигнал прошёл мимо
детектора), тест на регресс. Исходы «это дисциплина», «правило и так есть»,
«правок не завожу» запрещены. Своего рычага нет → искать (общий принцип затыка).

## Куда ложится урок (маршрутизация)

- **Урок к конкретной процедуре** (arc-маунты, сборка, тесты, PR-флоу) → секция
  «Грабли» соответствующего скилла в `~/.claude/skills/` или скиллов этого репо.
- **Сквозное правило домена** (стиль, тестирование, безопасность, воркфлоу) →
  правила кода (канон — страница «Правила кода» в Craft; пока её нет — «Грабли»
  ближайшего скилла с пометкой «кандидат в правила»).
- **Свежее неподтверждённое наблюдение** → инстинкт-контур (когда подключён) —
  автозапись без ока.
- **Знание о самой задаче/проекте** (решение с обоснованием, вывод исследования,
  статус) — не урок агента: оно идёт в Craft-проект Влада по правилам базы
  (лог задачи, где принято решение).

## Дисциплина записи

- Запись урока в скиллы/правила — системная правка: через план-гейт (план-мод →
  ок Влада), с показом формулировки и места. Автозапись без ока — только в
  инстинкт-контур.
- Пропущенный детектором сигнал инцидента → тем же разбором добавить маркер в
  `incident-markers.txt` (широкие паттерны легитимны: ложное срабатывание дёшево,
  пропуск дорог).
