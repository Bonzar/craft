# Консолидация инстинктов

Работа над Craft-доком «🤖 Инстинкты агента» (папка «Память для агента»):
подстраница «Наблюдения» — блок-ID `11126344-32e1-8c47-81d2-9079eac43f1f`,
подстраница «Инстинкты» — `b2b08ac0-b42e-382c-b1ee-8de5fb339fc6`. Обе читаются
целиком перед правками (read-before-write). Запись в этот док проходит
план-гейт без плана (предодобренная зона) — но действует только внутри дока:
любые правки ПРАВИЛ (системная зона) отсюда запрещены, для них — промоушен-план
с оком Влада.

## Процедура

1. **Прочитать обе подстраницы целиком** (--depth -1). Формат записи: один блок
   «[скоуп] при [сигнале] → [действии] (счёт: N, обновлено: дата)».
2. **Слить почти-дубли** в «Наблюдениях»: записи с одним root cause (тот же
   сигнал по смыслу, не по букве) объединяются в одну — счёт суммируется,
   формулировка берётся более точная, лишние блоки удаляются.
3. **Обновить счётчики**: повторившийся кандидат получает счёт+1 и свежую дату.
4. **Погасить угасшее**: кандидат без подтверждений дольше месяца удаляется.
   Инстинкт (уже переведённый) без подтверждений — понижается обратно в
   «Наблюдения», а не удаляется сразу.
5. **Защитить долгоживущее**: инстинкт со счётом ≥ 5 и историей от двух месяцев
   не гасится автоматически — только через промоушен-план (в правило) или
   явное решение Влада.
6. **Перевести подтверждённое**: кандидат со счётом ≥ 3, подтверждавшийся не
   из одной сессии, переносится блоком в «Инстинкты».
7. **Инвариант ≤ 50 блоков** на каждой странице: при переполнении — старейшие
   слабые записи в подстраницу-архив внутри дока (создать при первой нужде).
8. **Промоушен-планы**: инстинкт, устойчивый настолько, что тянет на постоянное
   правило (счёт ≥ 5, без противоречий), — кандидат в системную зону. Готовится
   план правок по правилам «Обслуживания памяти» и показывается Владу
   план-модом; в автономном прогоне — план откладывается и показывается, когда
   Влад в сети («Влад не в сети — не его отказ»).

## Грабли

- Дедуп — по root cause, не по тексту: «при сетевой ошибке curl → ретрай» и
  «при таймауте fetch → ретрай» — один кандидат про ретраи сетевых сбоев.
- Правки — только append/update/delete внутри этого дока. Блоки чужих доков,
  правила, роутер — не трогать: автономный байпас гейта распространяется
  только на предодобренную зону.
- Сырые логи и имена конкретных файлов в формулировке кандидата — дефект
  дистилляции: переформулировать обобщённо при слиянии.
