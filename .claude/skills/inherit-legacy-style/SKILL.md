# Шим: тело — в Craft

Тело скилла живёт в Craft-доке «⚙️ SKILL: Легаси-стиль окружения»
(block-ID `250d23a1-bf26-8719-08d2-98ad2c671f5b`). Прочитай его ЦЕЛИКОМ —
`blocks get 250d23a1-bf26-8719-08d2-98ad2c671f5b --depth -1` через Craft MCP —
и действуй строго по нему.

Craft недоступен (ни MCP, ни connect) — ЯВНО скажи Владу, что тело скилла
недоступно, и не имитируй процедуру по памяти или усечённой версии.
