# Наследовать стиль легаси

Дрейф стиля — когда агент накладывает мейнстрим-идиомы из претрейна поверх
чужого проекта. В легаси и монорепо Аркадии это дефект: смешение двух стилей
хуже, чем последовательный «несовременный». Выравнивается мета-архитектура,
не вкусовщина по синтаксису.

## Перед правкой — скан окружения

Прочитать 2-3 соседних файла того же слоя (соседи по директории, аналогичные
компоненты/модули) и снять конвенции по 4 измерениям:

1. **Анатомия файла** — порядок объявлений: импорты → типы → основная логика →
   хелперы → экспорт; один компонент на файл или несколько.
2. **Стейт и control flow** — нейминг асинхронных состояний, флагов, пагинации;
   mobx/rx-паттерны как в пакете, а не «как принято в интернете».
3. **Инфраструктура** — где живут кросс-катящие утилиты (форматтеры,
   интерсепторы): переиспользовать существующие, не заводить свои дубли.
4. **Ошибки** — try/catch, глобальный перехват или Result; привычки null-чеков.

Ориентир — большинство в окружении, не «лучшая практика». В Аркадии граница
скана — свой пакет (@crm/*): у соседних пакетов конвенции могут отличаться.

## Правила письма

- Новый код неотличим от соседнего: тот же нейминг, та же структура файла,
  те же библиотечные приёмы.
- Не «модернизировать заодно»: перевод на новые идиомы — отдельное решение
  Влада, не побочный эффект правки.
- Структуру эталона переиспользовать, баги из него — не копировать: заметил
  дефект в образце — подсветить, не воспроизводить.
- Улучшение стиля хочется предложить — предложить отдельно, после задачи,
  а не вплетать в дифф.

## Конфликт стилей — спросить, по одному

Окружение расколото почти поровну (файлы слоя пишут X и Y вперемешку) —
не выбирать молча: показать оба с путями-примерами и спросить, чему следовать.
Один вопрос за раз. Явное меньшинство (<5%) — вопроса не стоит, следовать
большинству.

## Грабли

- «Так пишут в новых доках библиотеки» — не аргумент против локальной
  конвенции: код живёт в этом пакете, а не в доках.
- Эталон для новой сущности — соседний файл того же слоя, а не файл из
  другого пакета/проекта.
