# Маркер пробы

Этот скилл - часть модуля-пробы, а не рабочий процесс. Он существует ради
одной строки: маркера в описании выше, который видно в списке скиллов
стартового контекста. По тому, какой маркер доехал, проба судит, собран ли
список скиллов до переустановки набора или после неё.

Вызвали - ответь одной строкой: «Маркер скилла: ЯНТАРНАЯ-РЫСЬ-1909» и всё.
Никаких других действий.
