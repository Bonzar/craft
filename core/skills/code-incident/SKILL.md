# Шим: тело — в Craft

Тело скилла живёт в Craft-доке «⚙️ SKILL: Разбор инцидента в коде»
(block-ID `5d712572-494f-5671-a362-dff65769bc05`). Прочитай его ЦЕЛИКОМ —
`blocks get 5d712572-494f-5671-a362-dff65769bc05 --depth -1` через Craft MCP —
и действуй строго по нему.

Craft недоступен (ни MCP, ни connect) — ЯВНО скажи Владу, что тело скилла
недоступно, и не имитируй процедуру по памяти или усечённой версии.
