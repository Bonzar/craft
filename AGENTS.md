# AGENTS.md

Прочитать в начале сессии целиком:

- `modules/behavior/rules/behavior.md` — как вести ход, спрашивать, показывать и отчитываться.
- `modules/craft-call/rules/craft-tool.md` — механика инструмента Craft: чтение и запись блоков.
- `modules/code/rules/code.md` — правила кода, стек-агностик.

Правила базы Craft и устройство системы живут в Craft, читаются по ссылкам:

- Проект стройки «Модульная система агента 🤖»: `blocks get 9a9b271a-3656-53e3-b933-72500de42db3 --depth 2`.
- Устройство системы агента: разделы сферы «Джарвис», корень «Архитектура #раздел»: `blocks get a2efce64-c813-7c06-3ce8-72714bdb545e --depth -1`, дальше по «Связям».
- Правила базы: разделы сферы «Личное», корень «Сущность базы #раздел»: `blocks get a6784801-9d92-875c-f146-50159368745b --depth -1`, дальше по «Связям».
- Память агента: `blocks get e8132891-81f4-2d63-36f1-d3623d0147b6 --depth -1`, читать целиком: это кэш фактов о Владе и диспетчер скиллов.
