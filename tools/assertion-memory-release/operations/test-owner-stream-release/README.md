# Ordinary owner SSE: protected TEST activation contract
Source-only policy; this directory is not an installer. No new browser path,
credential, permission, release override, or PROD service/route.

Constructor and hypothetical CLI planner default off. The actual immutable
feature source explicitly selects TEST in `owner_snapshot_release_policy.py`.
The normal protected Base executor installs the archive and restarts the
existing Graph. Its startup validates the existing owner-lane/dashboard
pair before consulting that reviewed boolean. TEST and PROD build the same
source; the latter stays dark. There is no need to adopt a systemd drop-in or
pass a new workflow input; rolling back the Base archive rolls back the
selection. `plan()` is a source-only argv review helper if explicit CLI
activation is considered; it is not the release executor.

Normal Base and Visual workflows use their existing TEST action and independent
published immutable release IDs for the same reviewed feature source; no old
tag rerun or PROD test_run_id. CI proves syntax/contract, not public delivery.
After protected activation, read actual owner browser versions and capability
bits, verify anonymous denial, no-store and unbuffered on existing same-origin
`/api/v1/events`; then run `prove()` against a single cold owner navigation with
one later authorized non-destructive synthetic event, no transcript or ticket
recorded. The root-trusted protected executor supplies measurements; browser
booleans are not authorization. If existing ingress buffers or omits the route,
stop without widening it; preserve previous good release and config. Reuse of
already-authorized TEST browser state does not authorize PROD access.
