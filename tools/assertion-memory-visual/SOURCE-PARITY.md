# Source renderer candidate; not the deployed TEST renderer

This local candidate overlays the audited c72f966 TypeScript, stylesheet and HTML on
the visual lifecycle draft infrastructure (8f4059d). The matching df0a24f input is
an earlier renderer baseline, not an alternate release. No native Site bundle or
private configuration is part of this candidate.

The layout toggle uses an independently implemented, edge-aware positioning path
without topic grouping. It preserves canonical topology, membership and revision,
stages the same hashed worker entry point and switches only when the new Scene
projection is accepted. This is not the private native Worker force-layout algorithm.
Mobile overview caps solid glyphs, not glass; existing source readiness notes are
deduplicated. The classic/non-camera 200-assertion cutoff remains. The physical
camera map deliberately keeps topic aggregation below that cutoff.

Validated locally with the TypeScript compiler, synthetic frontend assertions and a
release package with exactly one HTML, stylesheet, main JS and hashed Worker. Graph
behavior under owner login, WebGL rendering and interaction on a real iPhone are
not validated. Do not switch TEST or PROD on the strength of these checks alone.
