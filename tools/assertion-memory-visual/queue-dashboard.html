Очереди обработки

Подключаемся…

Очереди обрабатываются независимо. Номер указан только для задач, у которых есть место в очереди.

Пауза не запускает новые задачи для реплик, связей и пересчёта. Уже начатые задачи продолжаются. Очередь вопросов не затрагивается.

Очистка базы

Будут безвозвратно удалены реплики, мысли, связи и задачи этого окружения. Резервная копия не создаётся. Настройки и доступы не изменятся.
